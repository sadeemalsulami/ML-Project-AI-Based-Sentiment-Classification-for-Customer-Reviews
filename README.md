# Sentiment Analysis using Stacking Ensemble

## Overview
This project presents a machine learning solution for sentiment classification of customer reviews.

A Stacking Ensemble model was developed combining:
- Multinomial Naive Bayes
- Random Forest
- Linear SVC

with Logistic Regression as a meta-learner.

## Problem
Customer reviews are difficult to analyze manually due to:
- Large volume
- Sarcasm and ambiguity
- Class imbalance

## Approach
- Text preprocessing (cleaning, lemmatization)
- TF-IDF vectorization
- Random Oversampling for class imbalance
- Ensemble learning

## Results
- Accuracy: 82.63%
- Strong performance on positive & negative classes
- Neutral sentiment remains challenging
